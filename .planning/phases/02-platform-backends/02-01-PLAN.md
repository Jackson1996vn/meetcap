**Imports (top of file):**
```python
import logging
import threading
import numpy as np
import objc
from objc import super  # REQUIRED for argumentless super() in NSObject subclasses
from Foundation import NSObject, NSRunLoop, NSDate
from ScreenCaptureKit import (
    SCStream, SCShareableContent, SCStreamConfiguration, SCContentFilter,
    SCStreamOutputTypeAudio, SCStreamOutputTypeScreen,
)
from CoreMedia import CMSampleBufferGetNumSamples, CMSampleBufferGetFormatDescription
from AVFoundation import CMSampleBufferGetAudioBufferListWithRetainedBlockBuffer
```

**CaptureDelegate class (NSObject subclass):**
- `initWithCallback_(self, callback)` -- store callback as `self._callback`, return self. Uses `super().init()` (from objc import super).
- `stream_didOutputSampleBuffer_ofType_(self, stream, sampleBuffer, output_type)`:
  - If `output_type == SCStreamOutputTypeScreen`: return immediately (discard screen frames, required to avoid -3805 per Pitfall 2)
  - If `output_type == SCStreamOutputTypeAudio`: extract audio data from CMSampleBuffer, convert to numpy float32, mix to mono if stereo, call `self._callback(arr)`
  - DO NOT decorate with `@objc.python_method` -- this is called by Objective-C (Pitfall 1, the #647 root cause)
- `stream_didStopWithError_(self, stream, error)`:
  - Log warning with error details (per D-10: do not propagate, do not kill recording)
  - DO NOT decorate with `@objc.python_method`

**CMSampleBuffer to numpy extraction (in CaptureDelegate or helper):**
- Use `CMSampleBufferGetAudioBufferListWithRetainedBlockBuffer` to extract audio bytes
- Get format description via `CMSampleBufferGetFormatDescription(sampleBuffer)` to read channel count and sample format
- Convert raw bytes to numpy float32 array
- If stereo (2 channels): reshape to (-1, 2) and mean across axis=1 to produce mono (per D-12)
- NOTE: The exact PyObjC bridging for `CMSampleBufferGetAudioBufferListWithRetainedBlockBuffer` return value may need adaptation. The function returns a tuple in PyObjC. Try the call and inspect the return value structure. If the standard PyObjC bridge does not expose raw bytes directly, fall back to using `objc.callbackFor` or ctypes to access the AudioBuffer.mData pointer. Document what works in the code comments.

**MacOSAudioBackend class:**
- `__init__(self)`: initialize `self._stream = None`, `self._delegate = None`, `self._thread = None`, `self._running = False`
- `start(self, callback: AudioCallback) -> None`:
  1. Check Screen Recording permission by calling `SCShareableContent.getShareableContentWithCompletionHandler_` and waiting for the completion handler (use `threading.Event` to synchronize)
  2. In the completion handler: check if `content.displays()` is non-empty. If empty, this means Screen Recording permission is missing (Pitfall 3). Print a clear message: "Screen Recording permission required. Open System Settings > Privacy & Security > Screen Recording and enable your terminal app, then retry." Raise `PermissionError` with the same message.
  3. If displays are available: create SCStreamConfiguration:
     - `config.setCapturesAudio_(True)`
     - `config.setExcludesCurrentProcessAudio_(False)`
     - `config.setSampleRate_(48000)` (per D-11 -- ScreenCaptureKit resamples OS-side)
     - `config.setChannelCount_(2)` (capture stereo, mix to mono in callback)
     - Set `config.setMinimumFrameInterval_` to CMTime(1, 1) (1 fps) to minimize screen capture overhead
  4. Create SCContentFilter for full display: `SCContentFilter.alloc().initWithDisplay_excludingApplications_exceptingWindows_(display, [], [])`
  5. Create delegate: `self._delegate = CaptureDelegate.alloc().initWithCallback_(callback)` -- stored as instance attribute (D-07 retain fix)
  6. Create stream: `self._stream = SCStream.alloc().initWithFilter_configuration_delegate_(content_filter, config, self._delegate)`
  7. Add BOTH outputs (D-08, Pitfall 2):
     - `self._stream.addStreamOutput_type_sampleHandlerQueue_error_(self._delegate, SCStreamOutputTypeScreen, None, None)`
     - `self._stream.addStreamOutput_type_sampleHandlerQueue_error_(self._delegate, SCStreamOutputTypeAudio, None, None)`
  8. Start capture: `self._stream.startCaptureWithCompletionHandler_(self._on_start_complete)`
  9. Start a background thread that spins `NSRunLoop.currentRunLoop().run()` for callback delivery (D-08, Pitfall 5). The thread function should call `NSRunLoop.currentRunLoop().runUntilDate_(NSDate.distantFuture())` in a while loop checking `self._running`.
  10. Set `self._running = True`

- `stop(self) -> None`:
  1. Set `self._running = False`
  2. Call `self._stream.stopCaptureWithCompletionHandler_(lambda error: None)` if stream exists
  3. Join the background thread if it exists
  4. Set `self._stream = None`, `self._delegate = None`

- `_on_start_complete(self, error)`: if error, log warning (D-10). Otherwise log info "System audio capture started".

**Logging:** Use `logging.getLogger(__name__)` throughout. Log at INFO for start/stop, WARNING for errors (per D-10).

**CRITICAL anti-patterns to avoid (from RESEARCH.md):**
- Do NOT use `@objc.python_method` on delegate methods (Pitfall 1)
- Do NOT skip the screen output registration (Pitfall 2 -- causes -3805)
- Do NOT use `objc.retain()` or `objc.release()` -- they do not exist in modern PyObjC
- Do NOT store delegate in a local variable -- must be instance attribute (D-07)

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Python -> OS (ScreenCaptureKit) | PyObjC calls into macOS system framework; trust boundary at TCC permission check |
| OS -> Python (audio callbacks) | OS delivers CMSampleBuffers to Python delegate; must validate buffer sizes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Elevation of Privilege | TCC permission | mitigate | Use only the legitimate SCShareableContent API to trigger the system permission dialog (per D-09); never attempt private API bypass |
| T-02-02 | Tampering | CMSampleBuffer processing | mitigate | Validate CMSampleBufferGetNumSamples result before allocating numpy array; cap at 48000 frames (1 second) maximum per buffer |
| T-02-03 | Information Disclosure | Logging | mitigate | Log only metadata (frame count, buffer size, sample rate) in callbacks; never log raw PCM data or derived speech content |
| T-02-04 | Denial of Service | Run loop thread | accept | Background thread spinning NSRunLoop could hang on stop() if stream does not respond; mitigated by thread join timeout but accepted as low-risk for CLI tool |
</threat_model>
