**Imports:**
```python
import logging
import numpy as np
import pyaudiowpatch as pyaudio
```

**Helper function: `_find_loopback_device(p: pyaudio.PyAudio) -> dict`**
Per the verified PyAudioWPatch example (RESEARCH.md Pattern 3):
1. `wasapi_info = p.get_host_api_info_by_type(pyaudio.paWASAPI)` -- raises OSError if WASAPI unavailable
2. `default_speakers = p.get_device_info_by_index(wasapi_info["defaultOutputDevice"])`
3. If `default_speakers["isLoopbackDevice"]` is True, return it directly
4. Otherwise iterate `p.get_loopback_device_info_generator()` and find the one whose name contains `default_speakers["name"]`
5. If no match found: `raise RuntimeError("No WASAPI loopback device found. Run 'python -m pyaudiowpatch' to list available devices.")`

**WindowsAudioBackend class:**

`__init__(self)`:
- `self._p: pyaudio.PyAudio | None = None`
- `self._stream = None`
- `self._running = False`

`start(self, callback: AudioCallback) -> None`:
1. Create `self._p = pyaudio.PyAudio()`
2. Find loopback device: `loopback = _find_loopback_device(self._p)`
3. Read native sample rate: `native_rate = int(loopback["defaultSampleRate"])`
4. Read native channels: `native_channels = max(1, int(loopback.get("maxInputChannels", 2)))`
5. Create the callback wrapper `_make_stream_callback(callback, native_rate, native_channels)` (see below)
6. Open stream:
   ```python
   self._stream = self._p.open(
       format=pyaudio.paInt16,
       channels=native_channels,
       rate=native_rate,
       input=True,
       input_device_index=loopback["index"],
       frames_per_buffer=1024,
       stream_callback=stream_cb,
   )
   ```
   Use paInt16 format (per Pitfall 4 -- WASAPI loopback delivers int16 by default; do NOT assume float32).
7. `self._stream.start_stream()`
8. `self._running = True`
9. Log info: `logger.info("WASAPI loopback capture started (device: %s, rate: %d)", loopback["name"], native_rate)`

`stop(self) -> None`:
1. `self._running = False`
2. If `self._stream`: `self._stream.stop_stream()`, `self._stream.close()`
3. If `self._p`: `self._p.terminate()`
4. `self._stream = None`, `self._p = None`

**Stream callback factory: `_make_stream_callback(user_callback, native_rate, native_channels)`**
Returns a function with signature `callback(in_data, frame_count, time_info, status) -> (None, pyaudio.paContinue)`:
1. Convert bytes to numpy: `arr = np.frombuffer(in_data, dtype=np.int16).astype(np.float32) / 32768.0` (per Pitfall 4 -- int16 to float32 normalization)
2. Mix to mono if native_channels > 1: `arr = arr.reshape(-1, native_channels).mean(axis=1)` (per D-12)
3. Resample to 48 kHz if native_rate != 48000 (per D-11, Pitfall 6):
   ```python
   if native_rate != 48000:
       try:
           import samplerate
           arr = samplerate.resample(arr, 48000 / native_rate, 'sinc_best')
       except ImportError:
           # Fallback: linear interpolation (lower quality but functional)
           arr = np.interp(
               np.linspace(0, len(arr) - 1, int(len(arr) * 48000 / native_rate)),
               np.arange(len(arr)),
               arr,
           ).astype(np.float32)
   ```
4. Call `user_callback(arr)`
5. Return `(None, pyaudio.paContinue)`

**Logging:** Use `logging.getLogger(__name__)` throughout. Log at INFO for start/stop, WARNING for errors.

**CRITICAL anti-patterns to avoid (from RESEARCH.md):**
- Do NOT use `np.frombuffer(in_data, dtype=np.float32)` directly -- WASAPI delivers int16 (Pitfall 4)
- Do NOT assume the device runs at 48 kHz -- always check and resample if needed (Pitfall 6)
- Do NOT use sounddevice instead of PyAudioWPatch -- sounddevice/PortAudio does not support WASAPI loopback

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Python -> PyAudioWPatch -> WASAPI | PyAudioWPatch wraps PortAudio patched binary calling Windows WASAPI API |
| WASAPI -> Python (audio callback) | OS delivers raw audio bytes to Python callback; must validate buffer format |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05 | Tampering | Audio callback buffer | mitigate | Validate in_data length matches expected frame_count * channels * 2 (int16) before np.frombuffer; reject malformed buffers |
| T-02-06 | Information Disclosure | Logging | mitigate | Log only device name, sample rate, frame count; never log raw PCM data |
| T-02-07 | Denial of Service | Missing loopback device | accept | RuntimeError with clear message; user-initiated CLI tool, not a service |
</threat_model>
