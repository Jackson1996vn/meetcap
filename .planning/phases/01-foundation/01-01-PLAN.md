Create src/meetcap/cli.py implementing the CLI entry point per D-07, D-08, D-09.

The file must contain:

```python
import click
from datetime import datetime


@click.group(invoke_without_command=True)
@click.argument("title", required=False, default=None)
@click.pass_context
def main(ctx: click.Context, title: str | None) -> None:
    """Record a meeting. Provide a TITLE or let meetcap generate one."""
    if ctx.invoked_subcommand is not None:
        return

    # Config loading will be added in Plan 02
    # For now, stub the recording message

    if title is None:
        title = datetime.now().strftime("%Y-%m-%d-%H%M")

    click.echo(f"Starting recording: {title!r}")
    click.echo("Recording... (not yet implemented — stub for Phase 2)")
```

Key implementation details:
- Per D-08: No title argument = auto-generate timestamp-based title using `datetime.now().strftime("%Y-%m-%d-%H%M")` format (e.g., `2026-05-09-1430`)
- Per D-09: `@click.argument("title", required=False, default=None)` so `meetcap "My Meeting"` works as a positional argument
- Per CLI-01: `@click.group(invoke_without_command=True)` so `meetcap` without subcommands runs the recording flow
- The config loading and first-run wizard are NOT in this task -- Plan 02 adds them
- Do NOT add a `config` subcommand yet -- Plan 02 handles that

After creating cli.py, verify the entry point works:
